# Longspan 漫剧 · 视频效果根因分析报告

> 版本：v1.0  
> 日期：2026-10-22  
> 审核对象：`comic-drama`（漫剧/动态漫）技能全链路  
> 审核方式：逐文件代码审查 + 真实任务产物抽样比对（Run `fe78692a`《末班车》、`233a8a68`《末日废土》、`2942b7ea`《老渔夫的信》）  
> 关联文档：`MRD-Longspan.md`、`PRD-人物一致性与风格统一整改.md`、`PRD-演出约束与一致性分层.md`



---

## 一、结论先行

**架构与工程能力扎实，但"效果不好"的根因不是某一个 bug，而是产品把决定观感的最后一公里——「声音、人物一致性、画面动效」——降级成了可选项。**

一句话概括：

> Longspan 的「约束与留痕」骨架是对的（分镜、场景卡、镜头预算这些规范层都做对了），  
> 但「能力层」该接的三样东西没真正接通——**TTS/音效/BGM 没接、角色参考图在当前通道失效、  
> 图生视频的画质与审核风险没兜住**。结果是：落到观众眼睛里，是一部**声音缺席、人物偶发崩脸、  
> 动效质量不稳定的"半成品"**。

---

## 二、核心发现（按观感影响排序）

### 发现 1（最致命）：声音层是「纸面设计」，不是「产物」

这是"效果不好"的第一大原因，且**三个最新 Run 无一例外**。

| 证据                                   | 数据                                                                                 |
| ------------------------------------ | ---------------------------------------------------------------------------------- |
| 三个 Run 的 `render_props.json` 中 `bgm` | **全部为 `null`**                                                                     |
| 音频来源                                 | **全部为 `macos-say` 本机兜底**（`audio.json` 中 `is_fallback: true`，`provider: macos-say`） |
| 真实 TTS                               | 已实现（`tts.py` 的 OpenAI 兼容 `POST /v1/audio/speech`），但**从未启用**（`TTS_API_KEY` 为空）      |
| 音效/环境音                               | `compose.py`、`tools.py` 中**没有任何 bgm/sfx/音效处理代码**                                   |

**最讽刺的落差**：`voice.md`（C6 配音阶段）产出了一份专业级声音设计——12 个音效点位表（雨声、气刹、报站、心跳、说话前 1 秒绝对静音…）、BGM 铺垫曲线（低音弦乐从 -28dB 渐升到 -20dB）。**但这份设计没有一行被合进成片。**

- 男声配音：`LOCAL_VOICES` 里 `male → Tingting`（本机无普通话男声），只能"同音色降速 15% 模拟"，男女角色听起来是同一个机器女声。
- 悬疑片没有 BGM、没有环境音，情绪张力直接归零——在短视频语境里，这基本等于废片。

**根因**：C6 阶段只产出「方案文本」，TTS/音效库/BGM 合成这条「能力层」链路没有真正接通（或接通了但依赖外部 Key 未配置）。这恰是 MRD §0.2 里"能力层够用即接"该兜住的部分。

---

### 发现 2：角色一致性——PRD 写了对策，但真实链路里「参考图」失效

整改 PRD 本身质量很高（锚点硬校验、场景卡、镜头预算、A-B-A 编排都**真实落地**了，`fe78692a` 分镜一次通过、场景序列符合 A-B-A）。但**最治本的一招——角色参考图（subject_reference）——在当前主通道上失效**：

| 证据                | 数据                                                        |
| ----------------- | --------------------------------------------------------- |
| `images.json` 中标注 | 11 格写「参考图（subject_reference）未生效：万相文生图不支持人物参考图，已退化为纯文生图」   |
| 实际主通道             | `dashscope/wan2.2-t2i-plus`                               |
| PRD 已写好的解         | `PRD-演出约束` §10.5：主通道切 `qwen-image-3.0-pro`（支持参考图 + 画质高一档） |

**这是一个「文档往前跑、产物没跟上」的断点**：`qwen-image-3.0-pro` 通道的机制在代码里已经写好（`image.py` 的 `ImageChannel` 能力矩阵），但**实际任务仍在用不支持参考图的万相 t2i**。也就是说，换脸这个最痛的问题，在最新成片上依然没有被根治。

---

### 发现 3：图生视频与「动态漫」定位存在张力

为了"动起来"，接入 `Doubao-Seedance-2.5` 图生视频（12 格里 10~12 格视频化）。副作用：

1. **二次生成崩脸**：视频模型会重新生成画面细节，赛璐璐风格 + 人物五官在运动里容易崩（实测：司机肩章文字乱码、手部结构含糊）。
2. **审核误杀**：万相审核对"半写实人脸/空镜含人"偏保守，`fe78692a` 第 1 格被判"含不当内容"降级。
3. **成本**：全片视频化 = 12× 视频模型计费，与"动态漫（静态图+运镜）"的低成本定位有张力。

---

### 发现 4：占位图混进成片（已部分改善）

`fe78692a` 的第 1 格 `isPlaceholder: true`（SVG 占位图），因审核被拦降级，**出现在了最终成片开头**——观众第一眼看到的是"占位图·未接生图"卡片。

- 虽然按「禁止静默降级」铁律如实标注了，但对"第一次就出成品"的北极星指标是硬伤。
- **改善信号**：最新的 `233a8a68`、`2942b7ea` 已做到 `占位格: 0`，说明这条链路近期已在收敛。

## 三、根因归层（对应 PRD-演出约束 的四层杠杆）

| 层        | 手段             | 本项目现状                          | 问题定性            |
| -------- | -------------- | ------------------------------ | --------------- |
| L1 提示词   | 风格锚、反写实、锚点复用   | ✅ 已用满                          | 无               |
| L2 素材条件  | 参考图、定妆图、链式首尾帧  | ⚠️ **半覆盖**：链式首尾帧已上，**参考图通道失效** | **一致性未根治的直接原因** |
| L3 演出与剪辑 | 镜头预算、场景卡、A-B-A | ✅ 已落地（P0 完成）                   | 无               |
| — 声音层    | TTS / BGM / 音效 | ❌ **空白**（有方案无产物）               | **观感第一杀手**      |
| L4 模型训练  | LoRA / 微调      | ❌ 未用（正确定位：最后一张牌）               | 无               |

**关键判断**：问题高度集中在两处——**「声音层完全空白」** 和 **「L2 参考图通道失效」**。前者是"没接"，后者是"接了但用错通道"。这两处都不是"模型不够好"，而是"该接的能力没接对"。

## 四、修复优先级建议

| 优先级    | 动作                                                                           | 为什么                       | 预期收益              |
| ------ | ---------------------------------------------------------------------------- | ------------------------- | ----------------- |
| **P0** | **接通声音层**：配真实 TTS（Edge TTS/Azure 免费层即可）+ 至少 1 轨 BGM + 环境音效；`bgm` 不能再是 `null` | 声音占悬疑动态漫观感 50%+，是当前最大单点损失 | 观感从"哑片"到"成片"，最直接  |
| **P0** | **占位图不进成片**：生图/视频重做后仍失败 → "删格+记留痕"，而非塞进 final.mp4                            | 护住"第一次出成品"北极星             | 消除开头硬伤            |
| **P1** | **让 `qwen-image-3.0-pro` 通道真正生效**，替换当前 `wan2.2-t2i-plus`                     | 参考图生效 = 换脸治本 + 画质高一档      | 一致性从"靠文字锚"到"靠参考图" |
| **P1** | **图生视频加画质后检**：抽帧看人物五官是否崩，崩了退回静态运镜                                            | 避免"动起来反而更难看"              | 动效质量可控            |
| **P2** | 落地 MRD §0.6 的"返工率/换题材成本/TTFV"三条判定线看板                                         | 用数据决定继续投图生视频还是退回纯运镜       | 停止盲目加功能           |

---

## 五、一句总结给决策

**别急着做新功能。** 当前成片离"能看"的差距，不在"约束层"（那部分已经做得很漂亮），而&#x5728;**"声音没接"和"参考图用错通道"这两件具体的事上**。把 P0 的两件事做完，同一套流水线出来的成片，观感会有一个量级提升——这比再写一份 PRD 都更有价值。
