## 一、为什么动态漫"动起来"不等于"视频"

动态漫的动感来自四个廉价但有效的层次，成本从低到高：

| 层次 | 手段 | 成本 | 效果 |
|---|---|---|---|
| 1 | 画面推拉（scale 变化） | 极低 | 基础，能让静图"呼吸" |
| 2 | 分层视差（背景/中景/角色分离移动） | 低 | 立体感，是最划算的一层 |
| 3 | 粒子（蒸汽、火星、光斑、雨） | 低 | 氛围，能掩盖画面细节不足 |
| 4 | 逐字字幕 + 节奏点 | 低 | 引导视线，控制观感节奏 |

**四层全上，成本依然接近零**（本地渲染，无视频生成 API）。
所以本技能明确规定"运动主导"，禁止退化为分镜图轮播。

## 二、镜头运动的六个基本式

| 名称 | 实现 | 情绪 |
|---|---|---|
| 推进（zoom-in） | `scale: 1.0 → 1.12` | 聚焦、紧张升级 |
| 拉远（zoom-out） | `scale: 1.12 → 1.0` | 抽离、揭示环境 |
| 横移（pan） | `translateX` 线性 | 交代空间关系 |
| 上摇/下压 | `translateY` | 揭示高度关系 / 施压 |
| 跟拍 | `translate` 跟随主体 | 代入感 |
| 环绕 | 背景与角色反向位移（视差） | 强调、仪式感 |

**静止也是运动决策。** 全片至少留一格完全静止，通常放在反转之后——制造"时间停了一下"。

## 三、节奏：短视频的生死线

- **前 5 秒决定留存**。必须在第 1~2 格抛出冲突，不能做铺垫。
- 每格 4~6 秒。低于 4 秒看不清，高于 6 秒注意力流失。
- 节奏要有**段落差异**：开场最快 → 中段稍慢（给台词留重量）→ 爆发转快 → 收尾定格。
- **静音是武器**。在反转点抽掉所有声音，观众会本能地屏息。

## 四、跨格一致性的工程做法

问题本质：每次调用生图都是独立采样，脸/风格必然漂移。

三层防线：
1. **锚点复用**（本技能强制）——冻结描述词字符串，禁止重新描述角色
2. **参考图**（M1 引入）——把定妆图作为 image reference 传入
3. **风格种子**（M1 引入）——固定 seed 与风格 LoRA / 参数，减少采样漂移

**优先级**：锚点复用 > 参考图 > 风格种子。
因为锚点复用零成本、可立刻生效，且能解决大部分问题。

## 五、常见失败模式

| 症状 | 根因 | 对策 |
|---|---|---|
| 12 格像 12 张插图 | 没有镜头运动设计 | 逐格标注运动，渲染前校验"运动主导"承诺 |
| 每格都是中景 | 景别未做变化检查 | 输出景别序列，检查相邻格是否重复 |
| 角色越画越不像 | 每格重新描述角色 | 强制锚点原文复用 |
| 台词说完画面还在 | 未做时长核算 | 配音阶段建核算表，超出必须删字或改语速 |
| 节奏平板 | 每格等长 | 节奏表分段给不同平均时长 |
| 结尾无力 | 没有钩子 | 最后一格比倒数第二格更安静 |
| 花了钱但没效果 | 用视频生成 API 做本可以运镜完成的事 | 运镜 + 粒子替代视频生成，成本降两个数量级 |

## 六、成本参考（实测口径）

12 张 AI 分镜图 + 镜头运动 + 粒子 + 配乐 + TTS ≈ **$0.12 ~ $0.35 / 条 60 秒**。

**零视频生成 API 成本。** 这是选择"动态漫"而不是"AI 真人短剧"的核心经济理由：
后者的视频生成成本是前者的一到两个数量级。
