# 漫剧（动态漫）制作

## 这是什么

**动态漫** = 漫画分镜图 + 配音 + 镜头运动 + 字幕 → 竖屏短视频（9:16）。

**不是** AI 真人短剧。本技能**不生成真人视频**，不要调用任何"图生视频 / 文生视频"思路的方案。
画面来自 AI 生成的分镜图（或 M0 阶段的占位线框），动感来自**镜头运动**（推拉摇移、视差、粒子、逐字字幕），不是靠视频模型。

## 生产规格（默认值，用户可覆盖）

| 项 | 默认 | 说明 |
|---|---|---|
| 画幅 | 9:16 竖屏 | 1080×1920，适配短视频平台 |
| 单集时长 | 60 秒 | 允许 ±10% |
| 每格时长 | 4~6 秒 | 由此反推格数：60÷5 = 约 12 格 |
| 输出 | 分镜图 + 配音 + 时间轴 → 成片 mp4 | |

**格数不是拍脑袋定的**：`格数 = 总时长 ÷ 每格时长`。这是硬约束，在规格阶段就定死。

## 五条铁律

1. **一致性优先于华丽。**
   角色的脸型、发型、主色、服装一旦定下，后续每一格都必须复用**同一套描述词**。
   绝不允许"这一格画得更好看所以改了设定"——跨格不一致比画得普通更致命。

2. **每格只承载一个信息。**
   一格讲清一件事。堆两个动作的格子，观众看不清，等于没讲。

3. **时长是硬约束。**
   格数 × 每格秒数必须落在总时长 ±10% 内。超出时在**规格阶段**调整格数或每格时长，
   绝不允许在合成阶段偷偷加速镜头来凑数。

4. **禁止静默降级。**
   任何降级的动作（换占位图、省略音效、跳过某格）都必须 ① 写进 `record_decision`
   ② 在产物里显式标注。用户可以接受降级，但不能接受不知情。

5. **能在系统内解决的，不要变成用户的问题。**
   只有**创意方向**（题材、风格、人物设定、结局走向）才停下来问用户；
   技术细节（格子数、镜头运动方式、TTS 音色参数、字幕字号）自己定，并记录依据。

## 用户只说一句话时怎么工作

用户的输入可能只有一句："外卖小哥其实是隐藏的美食评论家，被米其林主厨约战"。

此时要做的是**约束分层**：

- **硬约束**（不能违反）：用户明确写出来的（题材、时长、集数、画风、平台）
- **软偏好**（倾向性）：用户没写但可从创意推知的（基调、节奏、受众）
- **自由区**（你决定）：镜头语言、转场方式、配角数量、具体台词措辞

**不要把用户没提的事情当成待确认项反复追问。** 场景越具体越好：给他一个"已经想好了"的方案，
他否定比他从零描述容易得多。这就是「最小可信路径」——先出东西，再让他改。

## 阶段说明

| 阶段 | 做什么 | 关键点 |
|---|---|---|
| C1 约束解析 | 把一句话拆成 硬约束/软偏好/自由区 | 不要提问，直接给出你的解读 |
| C2 生产规格 | 反推可执行规格：格数、节奏表、画风锚、预算 | 用户输入的时长/集数是**硬契约**，格数由它算出 |
| C3 剧本 ★关卡 | Logline → 人物小传 → 分集大纲 → 分镜脚本 | 出口必须停下来让用户确认方向 |
| C4 角色设计 ★关卡 | 角色卡 + 定妆描述，锁定一致性锚点 | 锚点是描述词的**原文**；可单角色改提示词重画定妆图 |
| C5 分镜绘制 ★关卡 | 逐格出画面描述 + 样片图 | 先出前 3 格样片并停下确认，可改可重画，再铺满 |
| C6 配音与音效 | 台词 → TTS；BGM 与音效方案 | 时长与画面严格对齐 |
| C7 合成 | 分镜运动、字幕、时间轴 → 成片 | 交付前做一次自审 |

**阶段顺序是硬约束，不是建议**：`C3 剧本 → C4 角色（含定妆图）→ C5 分镜`。
角色没定下来就画分镜，等于让每一格都画在临时描述上 —— 事后再补定妆图，
只能"对脸"，对不回已经画错的那 8 格。所以 C4 在快通道（草稿）里也要跑，
并且出口必须停下来等用户确认形象。

## 两条跨阶段契约

**① 数字契约（C2 产出，机器校验）**
`spec.json` 的 `total_duration_seconds` / `grid_count` / `episodes` 必须来自用户输入：
用户填了 38 秒就是 38 秒、填了 3 集就是 3 集；没填集数按 1 集做。
模型只能如实执行或如实报错，**不得改判**（实测事故：用户填 `episodes=-18`，
模型判成"无效输入"自行改成单集，后面每一格都建在错的数字上）。
校验器 `spec_duration` 逐项对账，偏离即判阶段失败。

**② 画风契约（C2 产出，逐格强制复用）**
`spec.json` 的 `style_anchor` 是这一集画风的**冻结英文串**（自带反写实条款）。
每一格生图提示词、每张定妆图都必须原文包含它 —— 生图入口做字符串级校验，
缺了自动补在开头并留痕。风格锚不再由生图阶段各自发挥（那正是"同一集两种画风"的根因）。
