# C3 · 剧本 ★ 关卡

> 这个阶段的出口会**停下来等用户确认**。方向错了要在这里拦住，而不是 20 分钟后。

## 目标

产出可拍摄的分镜剧本：Logline → 人物小传 → 分集大纲 → 逐格分镜脚本。

## 四段结构

**Logline（一句话）**
必须包含"谁、想要什么、被什么阻挡"。
> 反例：「一个外卖员和米其林主厨的故事」← 这是主题，不是 Logline。
> 正例：「一个伪装成外卖员的匿名美食评论家，被米其林二星主厨当众挑衅，被迫用一碗蛋炒饭证明自己是谁。」

**人物小传**
每人给：人物内核（他要什么、怕什么）、视觉锚点、可变部分。
不要写成履历表。**"他的克制不是懦弱，是没必要跟外行解释的疲惫"** 这种判断才是小传的价值。

**分集大纲**
按节奏段写，标出每段的功能与时间区间。

**分镜脚本（核心）**
每一格必须包含：
- 画面（发生了什么，具体到动作与视线）
- 镜头（景别 + 运动）
- 台词（没有就写「无」）
- 音效

## 硬要求

1. **一格一件事。** 堆两个动作的格子等于没讲。
2. **结尾必须有钩子。** 观众看完不点下一集，这条片子就是失败的。
3. **时长自检。** 台词字数 ÷ 语速 ≤ 该格秒数。超出就改语速或删字，不许在合成阶段加速糊过去。
4. **景别要有变化。** 12 格全是中景就是"会动的 PPT"。

## 输出

写入 `script.md`。

## 自检五问

1. Logline 里的"阻挡"具体吗？
2. 主角有没有一句能被记住的台词？
3. 反转是靠**信息**翻的，还是靠**音效**翻的？后者弱。
4. 结尾最后一个画面是不是比倒数第二个更安静？如果不是，钩子不成立。
5. 如果删掉任意一格，故事还成立吗？**成立的话，那一格就该删。**
