# C6 · 配音与音效

## 目标

分配音色、核算每句台词的时长、设计 BGM 与音效点位。

## 最重要的一件事：时长核算

这是动态漫最容易露馅的地方——**话说完了画面还在，或者画面切了话没说完**。

必须输出一张核算表：

| 格 | 台词 | 字数 | 预估时长 | 格时长 | 余量 |
|---|---|---|---|---|---|

**语速参考**：中文 3.5~5 字/秒（沉稳角色取下限，活泼角色取上限）。

- 余量 < 0 → 不合格。处理方式只有两种：**删字** 或 **在该格抬高语速**，并说明理由。
- 绝不允许"在合成阶段加速镜头来掩盖台词超时"。

## 音色设计

每个角色给：音向（高中低）/ 语速 / 情绪基调 / 一句"表演提示"。
表演提示要具体到可以指挥配音员的程度，例如：
> "全片不加情绪起伏，越平越有压迫感。"

## BGM 与音效点位表

按时间列出：起始时间 / 类型（环境/音效/BGM）/ 内容 / 音量(dB)。

**留白是设计的一部分。** 至少有一处刻意静音，通常放在反转点：
让观众听见"现场安静下来"。

## 必须额外产出的机器可读清单：`lines.json`

配音音频由 Harness 在你交出这份清单之后**自动合成**（无 TTS 服务时用本机语音，并如实标注音色有限）。
所以你不需要调用工具，但必须把"每句怎么念"写清楚：

```json
{
  "lines": [
    {
      "index": 3,
      "text": "你皱眉了。",
      "role": "male",
      "rate_wpm": 190,
      "note": "气声，几乎贴着耳边说"
    }
  ]
}
```

字段规则（不合规会直接判失败重做）：

- `index`：这句台词所属的**格号**，必须与 `panels.json` 里的格号对应上。
- `text`：只写要念出来的字。**不要写**"（停顿）""（冷笑）"这类提示 —— 提示写在 `note` 里，
  否则会被逐字念出来。也不要写 markdown 记号。
- `role`：`male` / `female` / `narrator` 三选一（本地兜底音色有限，靠语速区分角色）。
- `rate_wpm`：语速（字/分钟），一般 180~260。
- 只收录**真正要出声**的台词；群杂、纯音效不要写进来。全片无台词的格子不要出现。

## 必须额外产出的机器可读清单：`bgm.json`

BGM 由 Harness 在你交出这份清单之后**自动合成**（无音乐素材库时用程序化氛围音兜底，
并如实标注"非授权曲目、仅作垫底"）。你不需要调用工具，但必须声明"这集要什么氛围的底音"：

```json
{
  "enabled": true,
  "mood": "suspense",
  "strength": 0.35
}
```

字段规则（不合规会判失败重做）：

- `enabled`：`true` / `false`。本集**刻意无 BGM**（如反转点静音设计）时填 `false`，
  并在 voice.md 的 BGM 点位表里说明理由。
- `mood`：`suspense`（悬疑/紧张，低音持续 + 缓慢涨落）/ `warm`（温暖/治愈，柔和三和弦）/
  `neutral`（中性，极轻低频垫）三选一。对应 voice.md 点位表里 BGM 的主情绪。
- `strength`：`0~1` 的小数，BGM 整体响度（建议 0.25~0.4，不能盖过台词）。
  台词密集、情绪平缓的集取低值；无台词、靠氛围撑的集取高值。

## 自检

- 台词总时长占全片比例是多少？超过 60% 说明台词太满——**画面被台词挤掉了**。
- 静音点在你想要的位置吗？
- 每一句台词都能在它所属的格子里说完吗？
