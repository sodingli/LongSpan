# 合成与编辑方案

## 时间轴（12 格 × 5s = 60s）

| 格 | 起止 | 时长 | 镜头运动 | 转场 |
|---|---|---|---|---|
| 1 | 0:00-0:05 | 5.0s | 推进（zoom-in 1.0→1.12） | 硬切 |
| 2 | 0:05-0:10 | 5.0s | 极缓推（1.0→1.06）+ 呼吸抖动 | 硬切 |
| 3 | 0:10-0:15 | 5.0s | 横向缓移（x: -40→40） | 火光闪白 |
| 4 | 0:15-0:20 | 5.0s | 跟脚上摇（y: 20→-30） | 硬切 |
| 5 | 0:20-0:25 | 5.0s | 过肩反打，轻微手持感 | 硬切 |
| 6 | 0:25-0:30 | 5.0s | 快横移 + 运动模糊 | 甩镜 |
| 7 | 0:30-0:35 | 5.0s | 焦点转移（模拟） | 硬切 |
| 8 | 0:35-0:40 | 5.0s | 手部特写上摇 | 硬切 |
| 9 | 0:40-0:45 | 5.0s | 弧线环绕（±25° 视差） | 速度感闪切 ×2 |
| 10 | 0:45-0:50 | 5.0s | 俯拍下压 + 0.5× 慢动作 | 硬切 |
| 11 | 0:50-0:55 | 5.0s | **完全静止** | 硬切 |
| 12 | 0:55-1:00 | 5.0s | 远景平移 → 屏幕特写 | 定格 + 字幕 |

**总长 60.0s，落在 60s ±10% 容差内。**

## 交付承诺（渲染前硬校验，不满足则拦截，不允许静默降级）

1. **运动主导**：至少 10/12 格有可见镜头运动（格 2、11 为刻意静止）。不得退化为"分镜图轮播"。
2. **节奏变化**：每格时长不允许全部相同；前 3 格平均 ≤4.2s，中段 ≥5.0s（见 spec.json 的 rhythm_table）。
3. **无静默降级**：所有占位图、简化音效、跳过的效果，必须在产物中显式标注，并在决策留痕中留档。
4. **字幕可读**：字幕字号 ≥54px（1080 宽下），单行 ≤14 字，不允许压在被摄主体面部。

## 镜头运动实现（M1 · Remotion）

用 Remotion（React 组件化视频）实现，每格一个 `<Sequence>`：

- **推拉**：`interpolate(frame, [0, duration], [1.0, 1.12])` 作用于 `scale`
- **视差**：把 SVG 分层（背景 / 中景 / 角色 / 前景粒子），各层用不同 `translateX/Y` 系数
- **粒子**：蒸汽与火星用 CSS 动画 + `random()` 种子，保证每次渲染一致（可复现）
- **逐字字幕**：按音频时间戳切分字符，`opacity` 逐字插值
- **格 11 静止**：刻意不写任何动画，用渲染对比度与粒子完全静止来制造"时间停了"的感觉

## 渲染参数

- 分辨率 1080×1920，30fps，H.264 (yuv420p)
- 音频 48kHz 立体声，AAC
- 字幕硬烧（平台兼容性考虑），同时导出 `.srt`
- 输出：`ep01.mp4`（约 12~18MB）+ `ep01.srt`

## 自审清单（交付前自动执行）

- [ ] ffprobe 校验：总时长 54~66s、分辨率 1080×1920、音轨存在
- [ ] 4 点抽帧（0s / 20s / 40s / 55s）确认画面非黑屏、非空白
- [ ] 音频电平检查：无削波（峰值 ≤ -1dB）、格 11 段电平接近静音
- [ ] 字幕完整性：12 格台词全部出现在字幕轨
- [ ] 交付承诺 4 条逐条核对
